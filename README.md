# Portfólio | Matheus Thiago

Página pessoal "About Me" e portfólio de **Matheus Thiago**, desenvolvedor front-end iniciante de Florianópolis (SC), Brasil.

## Objetivo

Este projeto é o meu cartão de visitas na internet. Ele serve para:

- me apresentar de forma simples e direta;
- reunir meus contatos e redes em um só lugar;
- mostrar os projetos que já construí;
- praticar HTML, CSS e JavaScript em um projeto real, com código organizado em arquivos separados.

## O que tem na página

**Lado esquerdo**

  - **Instagram:** abre o perfil [@mthassad](https://www.instagram.com/mthassad/).
  - **GitHub:** abre o perfil [mtassad1](https://github.com/mtassad1).

- **Projects:** os projetos que desenvolvi, com resumo e link.

## Projetos

### Linha Escarlate
Projeto front-end demonstrativo: uma landing page para uma marca de moda de luxo fictícia, voltada a um público de alto padrão.

Elementos principais:
- banner principal com a identidade da marca;
- grade com 8 peças de roupa;
- visual elegante e minimalista, com vermelho apenas no nome da marca;
- layout responsivo.

**Tecnologias:** HTML, CSS e JavaScript.
**Ver online:** https://mtassad1.github.io/Landing-Page-Linha-escarlate/

## Tecnologias usadas neste portfólio

- **HTML5**, com estrutura semântica (`aside`, `main`, `section`, `nav`).
- **CSS3**, com Flexbox, rolagem com *scroll snap* e layout responsivo para celular.
- **JavaScript** puro, para copiar o e-mail e exibir o aviso.
- Fonte **Open Sans** (Google Fonts).

## Estrutura de arquivos

```
.
├── index.html   # estrutura da página
├── style.css    # estilos e responsividade
├── script.js    # cópia do e-mail e aviso

```

## Como rodar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Não precisa instalar nada.

## Acessibilidade

- Ícones com `aria-label`.
- Foco visível ao navegar pelo teclado.
- Aviso de e-mail copiado anunciado por leitores de tela (`aria-live`).
- Animações reduzidas para quem prefere menos movimento.
